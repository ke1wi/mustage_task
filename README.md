# Telegram Expense Tracker

Цей проект складається з двох основних компонентів:

1. **Bot** - Telegram-бот, що дозволяє користувачам керувати своїми витратами.
2. **Server** - Серверна частина, яка обробляє запити від бота, взаємодіє з базою даних і генерує звіти.

## Опис

Проект дозволяє користувачам легко відслідковувати витрати, конвертувати їх у долари США за актуальним курсом, а також створювати звіти у форматі `.xlsx` за вказаний період.

### Основні функції бота:

- **Додавання витрат**: Користувач може додати витрату, вказавши назву, дату і суму в гривнях. Бот автоматично конвертує суму в долари США.
- **Звіт про витрати**: Генерація звіту за певний період, з підсумковими витратами і можливістю експорту в формат `.xlsx`.
- **Редагування витрат**: Можливість редагувати існуючі витрати за ID.
- **Видалення витрат**: Видалення витрат за ID.

### Архітектура

Проект складається з двох основних частин:

- **Bot**: Telegram-бот написаний на Python з використанням бібліотеки `aiogram`, що взаємодіє з сервером для виконання CRUD операцій.
- **Server**: Сервер написаний на Python за допомогою фреймворку `FastAPI`, який обробляє запити, використовує базу даних PostgreSQL для збереження витрат, а також генерує звіти у форматі `.xlsx`.

Технології
	•	Telegram Bot: aiogram - для створення асинхронного бота.
	•	FastAPI: для розробки API серверу.
	•	SQLAlchemy: ORM для роботи з базою даних.
	•	PostgreSQL: для збереження даних.
	•	APSheduler: для планування задач (оновлення валютних курсів).
	•	openpyxl: для генерації .xlsx звітів.

Плани на майбутнє
	•	Додавання аутентифікації та авторизації для користувачів.
	•	Підключення до більшої кількості фінансових сервісів для автоматичного оновлення валютних курсів.
